1. 产品简介

CMIS Module Manager 是一款用于调测和管理符合 CMIS（Common Management Interface Specification）标准的光模块的桌面工具。支持读取模块身份信息、实时监控光功率与温度、配置数据通道（DataPath）、执行环回 / PRBS 诊断，以及直接读写任意寄存器。

支持的接口后端（Backend）

Backend说明
mock_coherent模拟 800G QSFP-DD 可调谐相干模块（C-band DWDM, DP-16QAM），无需硬件
mock_dr8模拟 800GBASE-DR8（8×100G PAM4, SMF 500m, EML 1310nm），无需硬件
mock_sr8模拟 800GBASE-SR8（8×100G PAM4, OM4 100m, VCSEL 850nm），无需硬件
mock_fr4x2模拟 2× 400GBASE-FR4（CWDM4 SMF 2km, EML 1310nm），无需硬件
ch341通过 CH341 USB 转 I2C 适配器连接真实模块
ch347通过 CH347 USB 转 I2C 适配器连接真实模块
ftdi通过 FTDI 系列芯片连接真实模块
ℹ 4 种 Mock 模块涵盖了主流 800G QSFP-DD 应用：长途相干、数据中心 500m、机架内 100m、园区 2km，可用于不同场景演示与培训。

3. USB 驱动安装指南

使用 CH341 或 CH347 适配器连接真实光模块前，需先在 Windows 中安装对应的 WCH USB 驱动。Mock 模式无需此步骤。

步骤一：识别你的硬件

外观特征芯片型号需安装的驱动
黑色小板，常见于淘宝低价 I2C 适配器CH341ACH341 驱动
蓝色板，支持更高速率（USB 2.0 High-Speed）CH347CH347 驱动

步骤二：下载驱动

  • WCH 官网（国内）：www.wch.cn
  • WCH 官网（国际）：www.wch-ic.com
  • 在搜索框输入芯片型号（CH341 或 CH347），进入产品页 → 下载 → Windows 驱动压缩包
  • CH341 驱动包文件名通常为 CH341SER.ZIP，内含 CH341SER.EXE
  • CH347 驱动包文件名通常为 CH347SER.ZIP，内含 CH347SER.EXE
  • CH347 额外步骤：CH347 的串口驱动安装包不一定包含 I2C 通信所需的 CH347DLL.dll。如果安装后工具仍显示 unavailable，需从 WCH 官网搜索 "CH347EVT"（开发资料包）下载，在压缩包内找到 CH347DLL.dll，复制到 CMIS_Module_Manager.exe 同一目录下即可

步骤三：安装

  1. 解压下载的压缩包。
  2. 运行压缩包内的 SETUP.EXE（或 CH341SER.EXE / CH347SER.EXE）。
  3. 在安装界面点击 安装（Install），等待提示"驱动预安装成功"。
  4. 将 USB 适配器插入电脑。
  5. 打开 设备管理器（Win + X → 设备管理器），在"端口（COM 和 LPT）"或"通用串行总线控制器"下应出现：
     · CH341：USB-SERIAL CH341 (COM×)
     · CH347：USB Enhanced Serial Port (COM×)

步骤四：验证

  1. 启动 CMIS_Module_Manager.exe。
  2. 在左侧 Backend 下拉菜单中，应出现 ch341 或 ch347 选项（状态 available）。
  3. 若未出现，点击 ↻ Refresh Backends 重新扫描。
ℹ CH341：安装驱动后 CH341DLL.dll 会自动注册到 System32，EXE 无需额外配置。
⚠ CH347 注意：CH347SER.EXE 安装的是串口驱动（设备管理器可识别设备），但 I2C 通信所需的 CH347DLL.dll 可能不会自动安装到系统。若工具显示 CH347 unavailable，请从 WCH 官网下载 CH347EVT 开发资料包，找到 CH347DLL.dll，复制到 EXE 同目录或 System32 下。
⚠ 若设备管理器中设备图标有黄色感叹号，说明驱动安装不完整。请右键该设备 → 更新驱动程序，或重新运行安装程序。

4. 启动程序

  1. 找到发行包中的 CMIS_Module_Manager.exe，双击运行。
  2. Windows 可能弹出 SmartScreen 提示"Windows 已保护您的电脑"：点击 更多信息 → 仍要运行。
  3. 弹出黑色控制台窗口，显示：
    CMIS Module Manager starting on http://127.0.0.1:5000
  4. 浏览器自动打开，显示工具主界面。
⚠ 控制台窗口必须保持开启。关闭它会停止服务器，浏览器页面将无法使用。
ℹ 如果浏览器未自动打开，请手动在地址栏输入：http://127.0.0.1:5000

5. 界面总览

  • 左侧面板：连接控制区，始终可见；底部显示公众号二维码
  • 右侧内容区：根据选中的标签页切换显示
  • 顶部状态栏：绿色圆点 = 已连接，红色 = 未连接

10. Diagnostics — 诊断工具

10.1 Loopback（环回）

模式说明Page / Addr
MediaSide Output媒体侧输出环回13h / 0xB4

10.2 PRBS Generator（PRBS 发生器）

每个 PRBS 块为 8 字节：Enable（使能位图）/ Invert（数据反转位图）/ ByteSwap（PAM4 MSB/LSB 交换位图）/ PreFEC（FEC 编码前注入）/ Pattern×4（4 字节, 4 bits/lane）。

分区EnInvertByteSwapPreFECPattern
Host-Side Generator13h/0x900x910x920x930x94–0x97
Media-Side Generator13h/0x980x990x9A0x9B0x9C–0x9F

支持码型：PRBS7 / PRBS9 / PRBS13 / PRBS15 / PRBS23 / PRBS31 及其 Q 变体，以及 SSPRQ（Table 8-105）。

10.3 PRBS Checker（PRBS 检测器）

分区EnInvertByteSwapPostFECPatternLOL 地址
Host-Side Checker13h/0xA00xA10xA20xA30xA4–0xA714h/0x8A
Media-Side Checker13h/0xA80xA90xAA0xAB0xAC–0xAF14h/0x8B

每 lane 对应 LOL 列显示 Pattern Checker Loss of Lock 状态：● 锁定 / LOL 失锁

10.4 BER Results（误码率）

向 14h/0x80 写入 Selector = 0x01 选择 BER F16 诊断。Host BER 在 14h/0xC0，Media BER 在 14h/0xD0，每通道 2 字节。

F16 解码公式（CMIS 5.3 十进制浮点）：BER = mantissa × 10^(exp − 24)，其中 bits[15:11]=exp, bits[10:0]=mantissa。

信号质量典型 pre-FEC BER
接近底噪（优良）< 1e-9 ~ 1e-8
正常工作1e-8 ~ 1e-4
边缘1e-4 ~ 1e-3
劣化> 1e-3

10.5 SNR Results（信噪比）

向 14h/0x80 写入 Selector = 0x06 选择 SNR 诊断。Host SNR 在 14h/0xD0，Media SNR 在 14h/0xF0，每通道 2 字节小端 u16，单位 1/256 dB。

典型 400G/800G 链路 SNR 范围：PAM4 DSP 输出约 15–22 dB，越高越好。低于 13 dB 通常意味着链路劣化。

ℹ BER / SNR 读取无需 PRBS 使能，直接反映当前链路质量。若同时开启 PRBS 发生/检测，结果对应 PRBS 码流质量。

10.6 Error / Bit Counters（误码/比特计数器）

使用 Page 14h Diagnostic Selectors 0x02–0x05 读取每通道累计的 Error Count 和 Total Bits Count（U64 小端序）。

Selector说明
0x02Host 侧 Lane 1–4 Error + Total Bits 计数
0x03Host 侧 Lane 5–8 计数
0x04Media 侧 Lane 1–4 计数
0x05Media 侧 Lane 5–8 计数

每通道 16 字节（8 字节 ErrorCount + 8 字节 TotalBitsCount）。TotalBitsCount 最低位为 PSL（Pattern Sync Loss）指示位：0=同步正常，1=曾经失锁。

GUI 同时计算并显示 BER(calc) = ErrorCount / TotalBitsCount 方便直读。

Current FrequencyROU32，单位 0.001 GHz → THz = val / 10^612h / 0xA8+lane×4
Target PowerRWS16，单位 0.01 dBm12h / 0xC8+lane×2
Tuning StatusRObit 1=TuningInProgress, bit 0=WavelengthUnlocked12h / 0xDE+lane
⚠ 修改 Grid / Channel 需要 DataPath 处于 Deactivated 状态。Fine Tuning 和 Target Power 可在非瞬态状态下修改。

10.8 状态机模拟（Mock 模式特性）

Mock 后端完整模拟了 CMIS 状态机行为，方便无硬件演示：

操作响应行为
Software ResetModuleState: Ready → LowPwr (0.3s) → PwrUp (0.5s) → Ready (0.8s)，所有 DataPath 经历 Deactivated → Activated
Enter LowPwrModuleState → LowPwr，所有 DataPath → Deactivated，TxPower = 0
Exit LowPwrModuleState → Ready，所有 DataPath → Activated
TX Disable被禁用 lane 的 TxPower 降为 0，TxFault 标志置位，DP State → Deactivated
Apply DataPathConfig Status 先变为 ConfigInProgress，DP State 经历 Init → TxTurnOn → Activated（约 0.5s）
PRBS Checker EnableLOL Flag 先置位（失锁），0.3s 后自动清除（锁定）
Laser Tune写入 Grid/Channel 后，Current Frequency 实时更新，Status 显示 Locked

11. Raw Registers — 寄存器直读写

11.1 读取寄存器

  1. 填写 Page（如 0x00、0x11）
  2. 填写 Address（起始地址，如 0x80）
  3. 填写 Length（读取字节数，1–128）
  4. 点击 Read

结果以十六进制 Dump 格式显示：

0x80: A1 B2 C3 D4 E5 F6 01 02  ........
0x88: 03 04 05 06 07 08 09 0A  ........

格式：地址: 十六进制字节  ASCII（不可打印字符显示为 .）

11.2 写入寄存器

  1. 填写 Page 和 Address
  2. 在 Write Data 输入框填入字节（空格分隔十六进制，如 1E 50 00）
  3. 点击 Write
ℹ 地址 ≥ 0x80 为上页寄存器，工具自动切页；地址 < 0x80 为下页，忽略 Page 字段。
✕ 警告：直接写寄存器可能影响模块正常工作，请在熟悉 CMIS 规范的前提下操作。

12. 常见问题排查

Q1双击 EXE 后控制台窗口一闪而过
原因：程序启动异常，通常是端口 5000 已被占用。
解决：右键 EXE → "以管理员身份运行"；或在任务管理器中找到占用 5000 端口的进程，关闭后重试。
Q2浏览器显示"无法访问此网站"
原因：控制台窗口已被关闭，服务器停止运行。
解决：重新双击 EXE 启动，保持控制台窗口开启。
Q3Backend 下拉菜单只显示 mock_coherent/dr8/sr8/fr4x2，没有 ch341/ch347/ftdi
可能原因及对应解决方法：
  • USB 适配器未插入 → 插入适配器后点击 ↻ Refresh Backends 重新扫描。
  • 驱动未安装 → 参考第 3 节《USB 驱动安装指南》，安装对应型号的 WCH 驱动后再刷新。
  • 驱动已安装但仍不显示 → 打开设备管理器，检查适配器图标是否有黄色感叹号；如有，请重新运行驱动安装程序。尝试拔出适配器并重新插入，再点击 ↻ Refresh Backends。
  • CH347 特有问题：设备管理器正常但工具显示 unavailable → 串口驱动（CH347SER.EXE）只让系统识别设备，但 I2C 通信需要 CH347DLL.dll，该文件可能未随驱动自动安装。从 WCH 官网下载 CH347EVT 开发资料包，找到 CH347DLL.dll，复制到 EXE 同目录，重启工具即可。详见第 3 节。
Q4点击 Connect 提示 "Connect failed"
原因：Backend / Bus / I2C 地址与实际设备不匹配，或模块未正确连接。
解决：确认 I2C 地址（光模块通常为 0x50）、Bus 编号正确；检查模块与适配器的物理连接。
Q5Monitoring 功率显示 −inf dBm 或全为 0
原因：模块处于低功耗状态，或无光纤输入（Rx 功率为 0 时 dBm = −∞）。
解决：检查 Module Info 中 Module State 是否为 ModuleReady；检查光纤连接。
Q6Mock 模式的数据是真实的吗？
不是。Mock 模式返回按 CMIS 5.3 规范构造的模拟数据（含动态波动和状态机响应），仅用于软件界面验证和培训演示，不反映真实模块状态。当前提供 4 种 profile：mock_coherent（800G 相干可调谐）、mock_dr8、mock_sr8、mock_fr4x2，分别模拟不同类型 800G QSFP-DD 模块。
Q7为什么 mock_dr8/sr8/fr4x2 的 Laser Tuning 卡片显示"非可调谐模块"？
原因：这些 profile 模拟的是固定波长激光器（EML / VCSEL），Media Interface Technology ≠ C-band/L-band tunable。
正常现象。只有 mock_coherent（Media Interface Tech = 0x10 C-band tunable）支持 Laser Tuning 功能。真实模块的 Page 04h GridSupported 寄存器若为 0，说明不支持调谐。
Q8mock_fr4x2 的 Host/Media Lanes 为什么显示 8 而不是 4？
2× 400G-FR4 模块通过 CMIS 广告两个独立的 400GBASE-FR4 应用（AppSel#1 占用 host 通道 1-4，AppSel#2 占用 host 通道 5-8），两个应用并发运行得到 800G 总容量。
GUI 会遍历所有 Application Descriptors 并计算最大并发通道数（非重叠应用相加）。Host Lanes 后括号中显示了每个 AppSel 的明细。
