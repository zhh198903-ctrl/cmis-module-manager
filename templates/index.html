Connect to configure DataPath.

TX Enable is the inverse of the TX Disable bitmask. Unticking it on any media lane of a running Data Path takes the whole path from DPActivated to DPInitialized, and ticking it again brings the path back through DPTxTurnOn (Eq. 6-12). AppSelect selects the application code (0–15 per lane). Click Apply to write and activate the configuration — that is ApplyDPInit (10h:143), which re-initialises the Data Path. Apply Immediate (10h:144) commits the same configuration without taking the Data Path down, on modules that advertise it.

Host Lane Switching1Dh / 136–191

Electrical LaneProvisionedActiveLast Commit Result

Read-only. Each row is an electrical host lane — the physical connection — and the nominal lane (7.8) it is connected to: Provisioned (1Dh:136–143) is what the host has written, Active (1Dh:184–191) what the switch is doing. Application and Data Path registers, and so every other panel here, number lanes by nominal lane. Switching works within each group of 8 lanes.

Media Lane Switching5.46Dh / 136–191

Internal LaneStagedActiveLast Commit Result

Staged (6Dh:136–143, RW) is what the host has written; Active (6Dh:184–191, RO) is what the switch is doing. Enabling alone does not commit, so the two differ until a commit succeeds. The mapping must be one-to-one onto external lanes 1–8: each internal media lane the module has goes to a different one, and a lane it does not have (00h:210) is 0 (7.9.3) — a permutation when it has all eight. Anything else is refused here, because the module rejects it after reporting the write as successful. A commit must also move each running Data Path whole or not at all (7.9.4) — swapping two lanes of one Data Path is refused while it is up.

Page 6Dh is banked: each bank switches within its own group of 8 lanes, and every target in the registers is numbered 1–8 inside that group — so a switch cannot move traffic between groups. On a module wider than 8 lanes the columns show the absolute lane and the register value is in the tooltip, that rule applies per group, and Stage, Enable and Commit are written to every group.

CounterL1L2L3L4 L5L6L7L8

Times the receiver re-acquired lock after the data path came up, cleared by the module at DPInit. Counts rising on a link that otherwise looks healthy mean it is repeatedly losing and regaining lock. Reset writes the lane counters only (60h:192–193).
