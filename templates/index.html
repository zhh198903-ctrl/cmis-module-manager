Lane Polarity Status5.460h / 128–129

DirectionL1L2L3L4 L5L6L7L8

A CMIS Flag is latched and cleared by the read that reports it, so a fault that came and went appears in exactly one refresh. Lanes that have fired since the history was cleared keep a ●! marker after the flag itself has gone. DP Changed is the module's own record that a data path reached a steady state through a real transition: a link that dropped and came back reads Activated at both ends, and this is the only sign it happened.

The polarity in effect now. It may legitimately differ from Default Polarity (01h:171–172) in Module Info, which advertises only the power-up polarity of a module whose polarity is programmable.

Media Lane Switching5.46Dh / 136–191

Internal LaneStagedActiveLast Commit Result

Staged (6Dh:136–143, RW) is what the host has written; Active (6Dh:184–191, RO) is what the switch is doing. Enabling alone does not commit, so the two differ until a commit succeeds. The mapping must be a permutation of the lanes — anything else is refused here, because the module rejects it after reporting the write as successful.

Acquisition Counters5.461h / 128–191

CounterL1L2L3L4 L5L6L7L8

Times the receiver re-acquired lock after the data path came up, cleared by the module at DPInit. Counts rising on a link that otherwise looks healthy mean it is repeatedly losing and regaining lock. Reset writes the lane counters only (60h:192–193).
